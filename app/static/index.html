    All measured signals vs authentic reference

    This tab reflects a second supervised model that can only exist when the training corpus carries per-generator labels (folders such as data/FAKE/stable_diffusion/). When they are absent, nothing is invented: the panel says so. Even when trained, it names only generators it was shown — an unfamiliar one comes back as UNKNOWN, never as the closest known class.

    Signals are computed on the model input grid ( px) after per-image z-scoring, then compared with the training-split reference distribution.

    Every candidate model trained on identical splits. Final score = 0.40·F1 + 0.25·ROC-AUC + 0.15·Accuracy + 0.10·Speed + 0.10·Efficiency.

    Metrics come from models/metrics.json, produced by python train.py / python -m ams evaluate. The test split is evaluated once per model, after threshold selection on validation.
